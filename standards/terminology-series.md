# Series Terminology

Terms used identically in every book and lab repository. Platform-specific frameworks live in each book's `docs/terminology.md`.

| Term | Meaning |
|---|---|
| AI Adoption Decision Ladder | Buy, Configure, Integrate, Build, Host |
| Workload Placement Map | Places workloads by data boundary, action autonomy and integration depth |
| Escalation Trigger Model | When an agent must hand to a person |
| Authority levels | L1 Inform, L2 Recommend, L3 Act with approval, L4 Act autonomously, Never |
| Evidence pack | result.json, report.md and manifest.json (SHA-256) written by every lab |
| Break it safely | Applying lab-changes/ to introduce a controlled failure |
| Prove the fix | Re-running after remediation and showing PASS |
