# Contributing

1. Changes to a book's labs go to that book's repository, not here. This repository then moves the submodule pointer to the new commit.
2. Changes to a shared standard go here first, then each active book repository adopts them.
3. Run `python scripts/check_series.py --run-tests` before opening a pull request.
4. Follow standards/writing-standard.md: Australian English, no em dashes, synthetic data only, no invented results.
