# Getting Started

1. Clone with submodules: `git clone --recurse-submodules <master repository URL>`.
2. Install: `python -m pip install -r requirements.txt` (Python 3.11 or later).
3. Check the series: `python scripts/check_series.py --run-tests`.
4. Open a book's labs: `cd books/book-01-microsoft-copilot` and follow its README, starting with Lab 0.1.

**GitHub Desktop users:** File > Clone repository clones submodules automatically. If a book folder is empty, open the master repository in a terminal (Repository > Open in Command Prompt) and run `git submodule update --init --recursive`.
